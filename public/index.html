Иконки SIMAI Framework

Сервис отдаёт шрифты Material Symbols, нарезанные ровно под те иконки, которые использует страница. Вместо нескольких мегабайт браузер загружает несколько килобайт.

Отдельно подключать ничего не нужно: SIMAI Framework сам запрашивает у сервиса нужный набор, когда на странице появляются <sf-icon>.

Пример

Эти иконки нарисованы шрифтом, который только что нарезал этот сервис.

  • homehome
  • searchsearch
  • settingssettings
  • languagelanguage
  • palettepalette
  • light_modelight_mode
  • dark_modedark_mode
  • devicesdevices
  • codecode
  • speedspeed
  • boltbolt
  • checkcheck

Как запросить набор напрямую

<link rel="stylesheet" href="https://icons.simai.io/ms/css?icon_names=home,search&type=outlined">

Стиль иконок задаёт type: outlined, rounded или sharp. Ещё можно указать заливку, насыщенность, градацию и оптический размер.

Адреса

АдресЧто возвращает
GET /ms/cssСтили с @font-face для запрошенных иконок.
GET /ms/font/<hash>.woff2Нарезанный шрифт.
GET /ms/meta/<hash>Описание собранного набора.
GET /healthСостояние сервиса.
